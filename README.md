# 🎓 Student Guidance System  
### (Personalized Learning + Performance Prediction + Career Recommendation Engine)

A full-stack system that analyzes student academic data, resume skills, learning history, and interests to provide:

- Personalized study recommendations  
- Performance prediction (ML)  
- Career pathway suggestions  
- Skill gap analysis  
- Resume skill extraction (NLP)

---

## 🚀 Tech Stack

### **Backend**
- Django + Django REST Framework  
- PostgreSQL  
- ML models using:  
  - scikit-learn  
  - XGBoost  
  - SentenceTransformers  
  - spaCy  

### **Frontend**
- React (will be built in Week 3–4)

### **ML/NLP**
- Student performance prediction  
- Skill extraction from resume  
- Sentence embeddings  
- Recommendation engine
